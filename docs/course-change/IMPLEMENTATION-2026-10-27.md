### Test coverage ที่เพิ่ม

- Flow A: submit → mock Reg Chula → processing → staff result → completed
- Flow C: submit → bulk approve พร้อมรายการล้มเหลว → audit ส่งต่อจำลอง → completed
- Concurrent approval: สองคำขออนุมัติพร้อมกันได้ผล 200/409 และมี event อนุมัติเพียงครั้งเดียว
- ปฏิเสธ route preview ที่เก่า และปฏิเสธคำร้องหลัง deadline
- Inbox fixture 206 รายการ: เข้าถึงครบทุกหน้า ไม่มีซ้ำ กรอง pending/done ได้ counts ตรงและไม่รั่วข้ามนิสิต
- Settings: staff-only, overlapping/inverted weeks, catalog mismatch, audit reason, before/after audit, stale edits และการเปลี่ยนนโยบายไม่แก้ flow ของคำร้องเดิม
