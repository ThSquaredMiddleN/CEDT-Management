# ทดลองเดโม ลด / ถอนรายวิชา — 28/10

เอกสารนี้เป็นชุดงานสำหรับให้เจ้าหน้าที่และนิสิตทดลอง ไม่ใช่ผลรับรองจากพี่นัท และไม่ใช่ระเบียบของหลักสูตร

## ก่อนเริ่ม

- ใช้ข้อมูลสาธิตเท่านั้น การอนุมัติและบันทึกผลในเดโมไม่เปลี่ยนทะเบียนจริง
- บัญชีตัวอย่างและวิธีเปิดระบบอยู่ใน README ของ prototype-1 ให้ผู้ดูแลเตรียมบัญชีให้ผู้ทดลอง
- วันเวลาที่หน้าจอแสดงเป็นเวลาประเทศไทย หากตั้งวันจำลองจะมีป้ายแจ้งชัดเจน
- ให้ผู้ทดลองทำเองก่อน ผู้สังเกตไม่บอกตำแหน่งปุ่มจนกว่าจะติดขัด จดคำที่ไม่เข้าใจ จุดที่หาไม่พบ และสิ่งที่คาดว่าจะเกิดขึ้น

## งานสำหรับนิสิต (ประมาณ 10 นาที)

| งาน | เกณฑ์สังเกต |
|---|---|
| หาว่าวันนี้ลดหรือถอนได้ถึงเมื่อไร | อ่านวันปิดรับได้ เข้าใจปุ่มที่เปิด/ปิด และสังเกตได้ว่าเป็นเดโม |
| เลือกวิชาหนึ่งที่ทำรายการได้และอ่านประกาศ | เลือกถูกวิชา เห็นสาเหตุของวิชาที่ทำรายการไม่ได้ และเข้าใจว่าข้อมูลลงทะเบียนยังเป็นตัวอย่าง |
| กรอกเหตุผล แล้วรีโหลดแท็บเดิม | กลับมาเห็นประเภท วิชา และเหตุผลเดิม พร้อมป้ายกู้คืนฉบับร่าง ยังไม่มีคำร้องถูกยื่นเอง |
| ตรวจทานและยื่นหนึ่งคำร้อง | ตรวจวิชา/เหตุผล/เส้นทางได้ก่อนยืนยัน พบเลขคำร้องหลังยื่น และไม่คิดว่าอนุมัติแล้วเท่ากับทะเบียนสำเร็จ |
| กลับมาหน้ายื่นใหม่ | ฟอร์มที่ส่งสำเร็จถูกล้าง ไม่มีป้ายฉบับร่างเก่าค้าง |
| ติดตามคำร้อง แล้วเปิดจากการแจ้งเตือน | พบคำร้องตรงรายการ บอกได้ว่ารอใคร/รออะไร และอ่านประวัติได้ |
| ยกเลิกคำร้องที่ยังรอพิจารณา | เห็นคำยืนยันก่อนยกเลิก สถานะและประวัติตรงกัน ไม่สามารถยกเลิกคำร้องที่ดำเนินการต่อแล้ว |
| ออกจากระบบและเปลี่ยนบัญชี | บัญชีใหม่ไม่เห็นคำร้องหรือฉบับร่างของบัญชีเดิม |

ผู้ดูแลอาจหยุด API ชั่วคราวในเครื่องทดสอบเพื่อทดลองข้อความขัดข้อง หากขาดสัญญาณหลังยืนยัน ให้ใช้ “ตรวจสอบผลการยื่น” ก่อนยื่นซ้ำ การตรวจนี้ไม่สร้างคำร้องใหม่

ฉบับร่างเก็บในแท็บเดิม แยกตามบัญชีและเทอม อายุไม่เกิน 24 ชั่วโมง ล้างเมื่อส่งสำเร็จ ล้างเอง หรือออกจากระบบ การปิดแท็บ/เปลี่ยนอุปกรณ์ไม่ใช่การบันทึกฉบับร่างบนเซิร์ฟเวอร์

| อ่านรายละเอียดและบอกขั้นตอนถัดไป | แยกผู้ยื่น เหตุผล ผู้พิจารณา เอกสาร และสถานะทะเบียนได้ |
| เลือก 2 รายการแล้วเปลี่ยนตัวกรอง | รายการที่เลือกถูกล้าง ไม่มีรายการนอกหน้าหลงเข้าไปอนุมัติ |

| ทดลองอนุมัติและไม่อนุมัติ | มีหน้าตรวจทาน ต้องกรอกเหตุผลเมื่อไม่อนุมัติ และอ่านผลรายรายการได้ |
| ทดลองบันทึกผลขั้นตอนปลายทาง | เข้าใจว่าการกดนี้บันทึกผลสาธิต และบอกได้ว่าหลักฐานจริงที่ต้องใช้คืออะไร (หากยังไม่ทราบให้จดเป็นคำถาม) |
| ตรวจหน้าตั้งค่าโดยยังไม่บันทึก | เข้าใจผลต่อคำร้องใหม่ เห็นคำเตือนช่วงเวลาทับซ้อน และไม่เสียข้อมูลโดยไม่ตั้งใจเมื่อสลับกลับกล่องงาน |

## ข้อมูลที่ใช้ยืนยัน flow กับพี่นัท

ให้เดินหนึ่งตัวอย่างจริงที่ปิดข้อมูลส่วนตัวแล้ว ตามลำดับนี้:

**วิชา/เทอม/รูปแบบ → วันเปิดและวันปิดรับ → ผู้รวบรวม → ผู้ลงนาม → เอกสารที่ส่งคืน → สิ่งที่นิสิตทำใน Reg Chula → ที่มาคำร้องฉบับที่สอง → ลำดับรวมไฟล์ → ใครส่ง PI → หลักฐานที่ถือว่าจบ**

ทำแยกสำหรับ Block 1–7, วิชาเลือกครึ่งเทอมแรก, ครึ่งเทอมหลัง และเต็มเทอม ข้อมูลที่ยังไม่ทราบให้เว้นไว้ ไม่ใช้ค่าตัวอย่างของเดโมแทนคำตอบ
